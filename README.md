# GameDex: A Game Logging Application

## About
GameDex is a retro-inspired, full-stack application that allows gamers to organise and showcase their video game libraries. It features a pixelated style, dynamic profile stats and seamless exploration of over 500,000 games.

🎮 [View Live App](https://gamedex-gamma.vercel.app/)


## Features
| Feature | Description |
|---------|-------------|
| 📝 Activity Feed | Real-time global and personal update logs featuring game additions and status changes |
| 🔎 Game Discovery | Browse trending games and explore 500,000+ titles powered by RAWG API |
| 📚 Library Manager | Track games and filter by status (Playing, Completed, Planning, Dropped) |
| 💡 Stats Breakdown | Dynamic player metrics featuring total hours, top genres and library completion rates  |
| 🎨 Customisation | Showcase your identity with custom avatars (Cloudinary/DiceBear) and personalised bios |
| 📱 Retro UI | Custom pixel-art interface built with Tailwind CSS combined with retro sound effects |
| 🔒 Auth & Security | Secure user authentication powered by JWTs and encrypted passwords |
